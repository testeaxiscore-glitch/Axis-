# Security Policy

Este repositório não contém o produto em produção e não aceita reports de vulnerabilidade relativos ao código comercial por issues públicas.

Se algum conteúdo deste case expuser acidentalmente informação sensível, credenciais ou dados pessoais, o repositório deve ser removido/corrigido imediatamente e qualquer segredo potencialmente exposto deve ser rotacionado.

## Regras para conteúdo público

- nunca publicar `.env` real;
- nunca publicar JWT secrets, API keys ou tokens;
- nunca publicar dumps de banco;
- nunca publicar dados reais de clientes;
- nunca publicar logs contendo PII;
- screenshots devem usar dados fictícios ou ambientes vazios;
- exemplos devem ser simplificados e revisados antes de publicação.
