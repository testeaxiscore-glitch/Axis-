# Screenshots

As imagens deste diretório são versões sanitizadas de ambientes de demonstração.

Antes de publicação, screenshots devem remover ou substituir:

- nomes e e-mails reais;
- slugs, IDs e URLs internas;
- valores financeiros reais;
- nomes de provedores quando não necessários;
- métricas operacionais sensíveis;
- tokens, custos, chaves ou identificadores técnicos.
