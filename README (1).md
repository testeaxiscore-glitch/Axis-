# Exemplos

Os arquivos desta pasta são **exemplos genéricos e simplificados escritos especificamente para o case público**.

Eles ilustram padrões arquiteturais sem reproduzir nomes, regras, schema ou código proprietário do produto real.

- `tenant_scope.py`: autorização por tenant e papel;
- `appointment_conflict.sql`: defesa transacional contra sobreposição concorrente;
- `idempotent_webhook.py`: processamento idempotente de evento externo;
- `ai_context_builder.py`: criação de contexto mínimo e autorizado para IA.
